# Compact Crafting Tooltips

A presentation-focused mod for **Graveyard Keeper 1.407** that makes item tooltips easier to read by compacting repeated crafting-location entries.

The initial goal is to group tiered variants of the same station into concise lines, for example `Zombie Farm I, II, III`, without changing recipes, progression, station behavior, item mechanics, or other tooltip information.

Development is evidence-first; current verified host/runtime findings live in `docs/VERIFIED_GAME_DATA.md`.
